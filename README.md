# news-image-20261123

One image summing up the world's news of **Monday 23 November 2026**:
Wall Street's record rebound after Nvidia's board reinstated Jensen
Huang as CEO (Nvidia +31.5%, S&P 500 +4.7%, Nasdaq +6.5%, Dow +1,448),
Ukraine sinking the Russian corvette Merkury off Libya, the Democrats
clinching a historic House majority of 258+ seats, a factory fire in
Indonesia killing 24 with dozens missing, and the WHO warning that
fighting in eastern DR Congo is hampering the Ebola response.

`main.py` (Python 3.13, standard library only) copies the bundled
`entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`. The poster itself was
drawn programmatically with PIL — every letter is rendered, nothing
is AI-generated text.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
